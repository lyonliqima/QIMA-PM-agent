## Notes for the agent (not part of the brief)

- **Never fabricate** repo names, team names, or service paths. If a section has no source-backed content, write *"Not found in scan"*.
- **Backtick all repo names and service identifiers** — they're code references; users will copy them into terminal / search.
- **Don't paste this brief into a PRD body** — the PRD links to it via §1 相关资料 row instead.
- **Length discipline**: 10 sections × average 25 lines = 250 lines. Aim for that, hard cap 300.
